## Phase 5b — cancel-at-period-end UX banner

User reported that clicking Cancel in the Customer Portal kept them
showing as Pro afterward. Root cause: Stripe's `cancel_at_period_end`
default is `true` — the subscription stays active until the end of
the current period. The activation is correctly `pro` until then.

Built a UX surface that signals this state so the user understands.

## Phase 8c — PDF outline-indent fix (PR #8)

User reported that the landscape share PDF wasn't visually indenting
child tasks despite literal whitespace being prepended. Root cause:
React-PDF's `<Text>` component collapses leading whitespace during
text shaping.

Fix in `lib/plansight-ai/pdf/share-view.tsx`:
- New `indentPtForOutline(task, baseLevel)` computes
  `(outlineLevel - baseLevel) * 8pt`.
- `normalizedBaseLevel = Math.min(...task.outlineLevel)` — some MPP
  plans start at outline 0, some at 1. Normalize so the shallowest
  task is always flush-left.
- Applied as `paddingLeft: 6 + indentPtForOutline(...)` on the task
  name `<Text>`, not as literal text.

### Migration 09
- `supabase/migrations/09_phase9_ai_usage_log.sql`:
  - `ai_usage_log` — one row per AI call (cache hits, real calls,

  - `explain_task_cache` — keyed by `(plan_content_hash, task_id)`.

  - `ai_spend_alerts` — keyed by `(user_id, year_month)`. Dedupe so
    one operator email per user per month.

### `lib/plansight-ai/ai-usage/`
Five modules, each best-effort (never throws on Supabase failure):
- `cost.ts` — Haiku pricing constants ($1 input / $5 output / $0.10
  cache read / $1.25 cache write per 1M tokens). `computeCostUsd`,
  `extractTokenUsage`.
- `usage-log.ts` — `logAiUsage(input)`: inserts into `ai_usage_log`.
  Defaults cost_usd to 0 for cache hits.
- `explain-task-cache.ts` — `getCachedExplanation` /
  `setCachedExplanation` keyed by content hash + task id.
- `rate-limit.ts` — `checkExplainTaskRateLimit(userId)` returns
  `{ kind: "allow" | "block", ... }`. 30/hr hard, 100/day soft,
  200/day hard. Counts non-cached, non-rate-limited rows since
  hour-ago / UTC midnight. Degrades open on Supabase outage.
- `spend-alert.ts` — `checkAndAlertSpend(userId, email)`: sums
  month's `cost_usd`, sends Resend HTTP email if > $3 and
  `ai_spend_alerts` doesn't already have a row for this month.

### Route changes
- `app/api/plansight/explain-task/route.ts` — full mitigation stack:

  2. Compute content hash, cache lookup. Hit → log + return.

  4. Live Claude call. Log tokens + cost. Cache the result.

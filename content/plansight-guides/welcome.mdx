This post is a placeholder template. The `draft: true` flag in the frontmatter keeps it out of the published guides index and the sitemap until you flip it to `false` (or remove the line).

## What lives in this folder

Every `.mdx` file under `content/plansight-guides/` becomes one guide page at `/products/plansight-ai/guides/<filename>`. The filename (without `.mdx`) is the URL slug. The frontmatter at the top of the file drives the title, description, date, and OG metadata.

## Required frontmatter

```
---
title: Your guide title
description: One-sentence summary that doubles as the SERP meta description.
publishedAt: 2026-05-15
---
```

Optional fields:

- `updatedAt: 2026-06-01` — surfaces a "updated" badge and updates `dateModified` in the Article schema.
- `ogImage: /products/plansight-ai/guides/og/your-slug.png` — per-post Open Graph image. Skip and the page falls back to the site default.
- `draft: true` — excludes the guide from the index, sitemap, and detail route. Use while drafting.

## What you can write

Plain markdown for prose. Headings, lists, links, code, blockquotes are all styled out of the box. Use h2 and h3 — h1 is reserved for the guide title.

## When you're ready to publish

1. Set `draft: false` (or remove the line).
2. Commit the file. The build re-reads the directory; the new guide shows up in the index and the sitemap.
3. Request indexing in Search Console for the new URL.

Delete this file once you don't need the template anymore.
